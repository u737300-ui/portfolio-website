# Arslan Kharal Portfolio

A personal portfolio for Arslan Kharal, a software developer building practical applications, business systems and interactive digital experiences.

## Technical foundation

- React and TypeScript
- Three.js and React Three Fiber
- GSAP and Lenis animation systems
- Vite and WebGL

## Getting started

```bash
npm install
npm run dev
```

Build for production with `npm run build` and check code quality with `npm run lint`.

## Content

Project and contact information is centralized in `src/config.ts`. Empty contact values are intentionally hidden from the interface until verified links are available.
